## Class Idenity
#### **1. What is the core fantasy of this class?**

What fantasy is the player fulfilling every session?  
(“Telekinetic knight,” “elemental brawler,” “shadow assassin,” etc.)

#### **2. What does this class do better than any other?**

What’s their unique, irreplaceable value in the party?

#### **3. What emotions or vibes should players feel while playing this class?**

Fast? Heavy? Strategic? Unpredictable? Calculated? Ferocious?

#### **4. What problems does this class solve for the party?**

Damage? Control? Buffing? Debuffing? Tanking? Mobility? Support?

#### **5. What should this class _never_ be allowed to do?**

Setting boundaries helps you avoid class bleed and keeps identity sharp.

## Core Mechanics

#### **6. What is the class’s signature resource or mechanic?**

Mana? Rage? Momentum? Stances? Charges? Focus Points?

#### **7. What does this resource encourage players to do?**

Spend aggressively? Build slowly? Combo? Move around?

#### **8. Does the class have a unique action economy twist?**

Examples:

- extra reaction
    
- empowered crits
    
- bonus actions after moving
    
- multi-action abilities
    
- upcasting core abilities
    

#### **9. How does the class interact with Favored/Hindered?**

Does it:

- generate advantage?
    
- mitigate disadvantage?
    
- convert advantage into damage?
    
- spend dice for special effects?
    

#### **10. What are the class's bread-and-butter actions each round?**

What do they do 70% of the time in combat?

## Subclass Considerations

Subclasses should meaningfully change how the class plays.

#### **11. What unique aspect does each subclass emphasize?**

Damage? Defense? Magic theme? Weapon specialty? Mobility? Minions?

#### **12. What part of the class engine does each subclass modify?**

This is key:

- Some rewrite the resource mechanic
    
- Some change action costs
    
- Some change crit effects
    
- Some grant alternative versions of core abilities
    

#### **13. What role does each subclass invite the player into?**

Blaster? Tank? Controller? Support? Bruiser?

#### **14. Do subclass feats interact differently with the core class abilities?**

Subclasses must feel like **full alternate builds**, not flavor tags.

## ⭐ **FEAT DESIGN QUESTIONS**

You have **48+ feats per class**, so each needs to matter.

#### **15. What new _choice_ does this feat introduce?**

Not just a number boost — a **playstyle decision**.

#### **16. How does this feat change how the class functions?**

Examples:

- Adds a crit rider
    
- Gives a new way to spend actions
    
- Unlocks a stance or combo
    
- Expands range or movement
    
- Lets you bend a rule once per encounter
    

#### **17. Does the feat support one of the class’s core fantasies?**

Never write “generic warrior stuff” for a class meant to be magical, and vice versa.

#### **18. Does the feat step on another class’s identity?**

If yes → rewrite it.

#### **19. Is the feat meaningful at its level?**

Ask:

- Does this feel like a power spike?
    
- Would a player be excited to take this?
    
- Does it compare favorably with feats at the same level?
    

#### **20. Does the feat chain well with others?**

Feats should support:

- build paths
    
- combo lines
    
- subclass synergy
    
- horizontal growth
    

#### **21. What problem does the feat solve?**

Damage? Utility? Defense? Mobility? Playstyle gap?

## ⭐ **SCALING & LONG-TERM DESIGN QUESTIONS**

#### **22. How does this class scale across levels?**

Damage? New features? Expanded action economy? Extra effects?

#### **23. What is this class’s “level 20 fantasy”?**

What is the ultimate version of this class supposed to look like?

#### **24. How do lower-level mechanics foreshadow high-level ones?**

The class should blossom, not transform abruptly.

#### **25. What happens to a class ability on a crit?**

Power fantasy thrives on crit riders.

#### **26. How does the class stay relevant in non-combat scenes?**

Skills, exploration tools, utility abilities, roleplay hooks.

#### **27. How does the class expand without becoming redundant?**

Classes should stay fresh as they gain feats — not bloated.

---

## ⭐ **OVERALL DESIGN CONSISTENCY QUESTIONS**

#### **28. Does every ability reinforce the class fantasy?**

If an ability doesn't support the core identity, cut or move it.

#### **29. Does the class encourage an active playstyle?**

Boring classes kill power fantasy.

#### **30. Is the class easy to build but deep to master?**

Simple core → deep feat trees and subclass choices.

#### **31. Does this class give players 3–5 meaningful decisions each round?**

The hallmark of great tactical design.

#### **32. Does the class feel powerful and expressive from level 1?**

No weak, unreliable early levels.
